# Claude Code 提示词样例 - 数据筛选

以下是使用 Claude Code / openClaw 进行A股题材数据筛选的提示词样例。

---

## 样例1：单只股票筛选

```
请读取 data/drafts/eastmoney/000001.json 文件内容，按照以下规则筛选题材信息：

### 移除规则
1. 公司澄清/否认涉及某业务的公告（如"不涉及XX"、"无XX业务"）
2. 纯财务数字（如"2025年Q3营收XXX亿"，无题材指向）
3. 纯股价变动信息
4. 重复/同义的概念描述（保留更具体的那一条）

### 保留规则
1. 概念板块归属信息
2. 主营业务描述
3. 子公司、参股公司及其业务方向
4. 合作方、客户、供应商关系
5. 新业务布局、投资方向
6. 技术专利、资质认证

请输出筛选后的有效信息列表，标注每条信息的类别（板块/主营/子公司/合作/投资/其他）。
```

## 样例2：批量筛选（带上下文）

```
我正在整理A股题材向量库的数据。请帮我处理以下 5 只股票的草稿数据。

对于每只股票，请：
1. 读取 data/drafts/merged/{code}.json
2. 筛选出有效的题材信息（去除澄清公告、纯财务数据、重复信息）
3. 将筛选结果输出为 JSON 格式

待处理股票代码：000001, 000002, 600000, 600519, 300750

筛选时特别注意：
- "公司澄清不涉及XX业务" 类信息必须移除，否则会导致向量化后的误判
- 概念板块中的 "融资融券"、"深股通"、"沪股通" 是交易属性而非题材，可以保留但不作为核心题材
```

## 样例3：澄清公告识别

```
请检查 data/drafts/eastmoney/002594.json 中是否包含澄清类信息。

澄清类信息的特征：
- 包含"澄清"、"否认"、"无关"、"不涉及"、"未参与"等关键词
- 公司声明与某个热门题材无关联
- 投资者互动中明确否认某业务

如果发现此类信息，请标记出来并说明应移除的原因。
这些信息如果被保留并向量化，会导致系统误认为公司与该题材相关。
```
