# Claude Code 提示词样例 - 题材摘要生成

以下是使用 Claude Code / openClaw 生成A股题材结构化摘要的提示词样例。

---

## 样例1：从筛选数据生成摘要（推荐流程）

```
请根据以下已筛选的信息，为股票 000001 平安银行 生成结构化题材摘要。

【已筛选信息】
- 东方财富概念: 银行, 深股通, 融资融券, 数字货币, 区块链, 征信, 参股券商
- 同花顺概念: 银行, 深证成指成分, 互联网金融, 数字人民币
- 行业: 银行业
- 主营: 向企业、机构及个人客户提供多元化、综合化的金融服务
- 实控人: 中国平安保险(集团)股份有限公司
- 子公司: 平安理财有限责任公司(理财子公司)

请按以下格式写入 data/summaries/000001_平安银行.md：

# 000001 平安银行

## 所属板块
（此处列出东方财富和同花顺概念）

## 主营业务
（精炼描述，1-3句）

## 题材标签
（从概念板块中提炼核心题材标签，去除交易属性标签）

## 产业关系
（列出子公司、参股、合作方等）

## 实控人与管理层
（列出实控人、创始人等）
```

## 样例2：从草稿数据直接生成（一步完成）

```
请读取 data/drafts/merged/600519.json，执行以下操作：

1. 筛选有效题材信息（去除澄清/财务/重复）
2. 生成结构化摘要

将摘要写入 data/summaries/600519_贵州茅台.md，格式如下：

# 600519 贵州茅台

## 所属板块
- 东方财富概念: ...
- 同花顺概念: ...
- 行业分类: ...

## 主营业务
（简洁描述）

## 题材标签
（核心题材关键词，逗号分隔）

## 产业关系
- **子公司**: ...
- **合作方**: ...
- **产业上游**: ...
- **产业下游**: ...

## 实控人与管理层
- 实际控制人: ...

注意：
- 摘要控制在200-500字
- 不要编造草稿数据中不存在的信息
- 无数据的章节标注"暂无数据"
```

## 样例3：批量生成摘要

```
请批量处理以下股票，为每只生成题材摘要 MD 文件：

股票列表（从 data/drafts/merged/ 读取）：
- 600519
- 000858
- 000568
- 603369

对每只股票：
1. 读取 data/drafts/merged/{code}.json
2. 提取股票名称
3. 筛选有效信息并生成摘要
4. 写入 data/summaries/{code}_{name}.md

完成后请汇总处理结果（每只股票的概念数量、题材标签数量）。
```

## 样例4：摘要质量校对

```
请读取 data/summaries/000001_平安银行.md，检查以下质量项：

1. 是否包含标准章节：所属板块、主营业务、题材标签、产业关系
2. 主营业务描述是否准确、简洁
3. 题材标签是否包含了该股票的核心题材
4. 是否有明显遗漏的重要概念
5. 是否混入了应被筛选掉的无效信息

如有问题请直接修正并覆盖写入。
```
