# Claude Code 提示词样例 - 题材摘要生成

以下是使用 Claude Code / openClaw 生成A股题材结构化摘要的提示词样例。

---

## 样例1：从筛选数据生成摘要（推荐流程）

```
请根据以下已筛选的信息，为股票 000001 平安银行 生成结构化题材摘要。

【已筛选信息】
- 东方财富概念: 银行, 深股通, 融资融券, 数字货币, 区块链, 征信, 参股券商
- 同花顺概念: 银行, 深证成指成分, 互联网金融, 数字人民币
- 行业: 银行业
- 主营: 向企业、机构及个人客户提供多元化、综合化的金融服务
- 实控人: 中国平安保险(集团)股份有限公司
- 子公司: 平安理财有限责任公司(理财子公司)

请按以下格式写入 data/summaries/000001_平安银行.md：

# 平安银行 (000001)

（在此处撰写一句极具冲击力的引言，概括该公司的行业地位或核心亮点）

## 核心题材
1. **（核心题材名称1，如：XX龙头）(核心营收)**：（精炼描述其在该题材下的业务实力、市占率或营收占比）
2. **（核心题材名称2）(战略亮点)**：（描述该题材的未来增长潜力或战略布局）
3. **（核心题材名称3）(政策催化/其他)**：（描述该题材相关的背书、政策或增量逻辑）

## 业务亮点
- **（业务壁垒/护城河总结，如：极高的用户粘性）**：（详细说明该壁垒形成的原因及效果）
- **（资源/技术/转型亮点总结）**：（说明公司在行业内独有的资源禀赋或转型方向）
```

## 样例2：从草稿数据直接生成（一步完成）

```
请读取 data/drafts/merged/600519.json，执行以下操作：

1. 筛选有效题材信息（去除澄清/财务/重复）
2. 生成结构化摘要

将摘要写入 data/summaries/600519_贵州茅台.md，格式如下：

# 贵州茅台 (600519)

（一句极具冲击力的引言，概括行业绝对地位）

## 核心题材
1. **（题材名称）(核心主业)**：...
2. **（题材名称）(亮点/第二曲线)**：...
3. **（题材名称）(背书/护城河)**：...

## 业务亮点
- **（护城河总结）**：...
- **（核心资源池体现）**：...

注意：
- 摘要控制在200-500字
- 必须使用上述具冲击力和抓重点的结构（不要平铺直叙列出所有概念）
- 不要编造草稿数据中不存在的信息
```

## 样例3：批量生成摘要

```
请批量处理以下股票，为每只生成题材摘要 MD 文件：

股票列表（从 data/drafts/merged/ 读取）：
- 600519
- 000858
- 000568
- 603369

对每只股票：
1. 读取 data/drafts/merged/{code}.json
2. 提取股票名称
3. 筛选有效信息并生成摘要
4. 写入 data/summaries/{code}_{name}.md

完成后请汇总处理结果（每只股票的概念数量、题材标签数量）。
```

## 样例4：摘要质量校对

```
请读取 data/summaries/000001_平安银行.md，检查以下质量项：

1. 结构是否符合新标准：一句式引言、核心题材（带标注）、业务亮点
2. 引言是否具有足够的“冲击力”和信息密度
3. 核心题材是否真正抓住了公司的主要营收和未来增长点（而非简单的概念罗列）
4. 业务亮点是否清晰指出了公司的护城河、资源壁垒或转型方向
5. 是否混入了应被筛选掉的无效信息（例如纯粹的交易属性“融资融券”被当成核心题材）

如发现结构陈旧（如保留了老的“所属板块”、“主营业务”章节）或内容平淡，请直接修正并覆盖写入。
```
