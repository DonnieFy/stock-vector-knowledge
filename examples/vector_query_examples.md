# 向量数据库查询示例 (Vector Query Examples)

本文档展示了 `svk` 命令查询 ChromaDB 向量知识库的常见方式和实际输出效果，方便您直观了解如何通过语义或关联性检索 A 股题材。

---

## 1. 文本语义检索 (`svk query`)

基于自然语言的语义检索，寻找与输入概念/题材最相关的上市公司。

**命令示例:**
```bash
svk query "具身智能机器人" --top 5
```

## 2. 相似股票推荐 (`svk similar`)

输入一只您关注的股票代码，系统会基于所有上市公司的“核心题材、业务亮点、技术壁垒”进行降维匹配，找出全市场业务模式或卡位逻辑最相似的其他标的。

**命令示例:**
```bash
# 查询 920932 (科达自控，核心题材：智慧矿山、无人驾驶、AI大模型)
svk similar 920932 --top 5
```

## 3. 股票拓扑聚类分析 (`svk cluster`)

输入多只股票代码，系统基于它们的向量特征，使用 KMeans 算法在多维空间中将它们划分归类。这可以帮助您快速理清一堆自选股之间的业务派系或产业协同关系。

**命令示例:**
```bash
# 输入：科达自控(智慧矿山)、贵州茅台(消费)、宁德时代(新能源)
svk cluster 920932 600519 300750 
```

**实际输出效果:**
```text
═══ 聚类 0 (1只) ═══
  代表股: 600519 贵州茅台
  • 600519 贵州茅台

═══ 聚类 1 (1只) ═══
  代表股: 920932 科达自控
  • 920932 科达自控

═══ 聚类 2 (1只) ═══
  代表股: 300750 宁德时代
  • 300750 宁德时代
```
**解读**：当传入业务毫不相干的龙头标的时，向量聚类能够敏锐捕捉特征差异，将它们分别归入独立的群组（簇）。如果在输入大量同行业股票时（比如一打半导体和一打医药股），聚类算法会自动将它们划分成两大甚至多大阵营。

## 4. 股票池语义主题分析 (`svk analyze`)

该功能基于**双 ChromaDB Collection 架构**：构建阶段用 jieba 从全库 5500 篇摘要中提取约 14000 个关键词（IDF 过滤去噪），embed 后存入独立的 `theme_keywords` 集合。查询时计算输入股票的**质心向量**，用质心去关键词集合中做语义匹配，找出这批股票共同指向的细粒度概念方向。

**查询耗时约 100ms**，无需加载 embedding 模型。

### 4.2 实战场景：2026年3月11日涨幅前100

